## 👨‍💻 Giới thiệu

Mình thích học bằng cách tự tay xây dựng các dự án có thể tương tác và giải quyết vấn đề thực tế. Những sản phẩm mình đã thử sức trải rộng từ **web full-stack, Android, IoT, game** đến **AI và xử lý dữ liệu**. Qua đó, mình đang tích lũy kinh nghiệm về thiết kế giao diện, API, cơ sở dữ liệu, kiến trúc phần mềm, kiểm thử và triển khai.

## 🧰 Công nghệ đã sử dụng

- **Ngôn ngữ:** Python, JavaScript/TypeScript, Kotlin, C/C++, C#, PHP, SQL
- **Web:** React, Vite, Node.js/Express, FastAPI
- **Mobile:** Android, Jetpack Compose, Kotlin Coroutines
- **IoT & realtime:** MQTT, WebSocket, PostgreSQL, Prisma
- **AI & dữ liệu:** tích hợp mô hình AI, RAG, dữ liệu thị trường và các dịch vụ API
- **Game:** Pygame, SDL, Unity
- **Cloud & công cụ:** AWS, Docker, Git

> Danh sách trên phản ánh công nghệ xuất hiện trong các dự án cá nhân/đồ án, không phải mức độ chuyên môn hay kinh nghiệm production được xác nhận.

## 🌟 Một số dự án nổi bật

### [Fav Web — nhận diện khuôn mặt và nền tảng giải trí](https://github.com/RuMeoDiNhau/Favourite-Web)
Ứng dụng web kết hợp đăng nhập Face ID, bảng tin, âm nhạc, game và dashboard. Dự án sử dụng React/Vite ở frontend, FastAPI ở backend, đồng thời thử nghiệm JWT, phân quyền admin/user, Docker và lưu trữ AWS S3.

### [Smart Home — hệ thống nhà thông minh](https://github.com/RuMeoDiNhau/Do_An_Da_Nganh)
Đồ án IoT với backend Node.js/Express, PostgreSQL/Prisma, MQTT và WebSocket. Có các luồng quản lý thiết bị, điều khiển thiết bị, dữ liệu môi trường, ngưỡng cảnh báo và giao diện dashboard.

### [Wi‑Fi Location Optimizer — Android](https://github.com/RuMeoDiNhau/Mobile_Wifi_Optimizer)
Ứng dụng Kotlin/Jetpack Compose đo và so sánh chất lượng kết nối Wi‑Fi theo nhu cầu sử dụng. Dự án tập trung vào Clean Architecture/MVVM, luồng dữ liệu bất đồng bộ, quyền Android và cách trình bày kết quả đo.

### [Turn Battle Game](https://github.com/RuMeoDiNhau/Game-2D-Turn-Based-strategy)
Game chiến thuật theo lượt viết bằng C/C++ và SDL, có hệ thống thẻ, hiệu ứng bonus, nhiều mức độ khó và các kiểu AI như Random, Minimax, Monte Carlo Tree Search.

### [Crypto Telegram Bot](https://github.com/RuMeoDiNhau/bot_crypto)
Bot Python cung cấp lệnh tra cứu giá/thị trường và thử nghiệm phân tích crypto bằng dữ liệu Binance, dịch vụ AI và RAG. Đây là dự án kỹ thuật/tham khảo, không phải lời khuyên đầu tư.

### [Whack A Shin](https://github.com/RuMeoDiNhau/Game-Whack-A-Shin)
Game arcade nhỏ làm với Python và Pygame: mục tiêu di chuyển theo cấp độ, tính điểm/combo, lưu điểm cao và có menu âm thanh.
